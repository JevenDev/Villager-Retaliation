# Controls & Configuration

## Default controls

- Quest Journal: :key[key.villagerretaliation.open_quest_journal]
- Quest Tracker: :key[key.villagerretaliation.toggle_quest_tracker]
- Party Quick Commands: :key[key.villagerretaliation.quick_command]
- Blueprint Placement Lock: :key[key.villagerretaliation.toggle_blueprint_placement_lock] (unbound by default)
- Toggle Villager Name Tags: :key[key.villagerretaliation.toggle_villager_name_tags] (unbound by default)
- Bypass interaction screen: sneak + :key[use] by default

Open Mod Menu and choose **Villager Retaliation** to adjust available settings. In multiplayer, the server owns gameplay rules; display and key preferences remain client-side where supported.

Server-controlled areas include contracts, wages, work limits, reputation, combat, raids, recovery, gifts, quests, social rules, and datapack content. Local settings include keybinds, name tags, HUD placement, presentation, and other supported visuals.

:::notice{type="info"}
If this guide disagrees with a price, threshold, duration, quest, or gift on your server, use the in-game value. Server configuration and datapacks intentionally override the built-in defaults.
:::

Optional integrations:

- **Second Wind:** adds channeled early revival and a crawl presentation to protected downed villagers.
- **Ride On 1.0.0-pre-release.3+:** adds supported two-seat mount behavior.
