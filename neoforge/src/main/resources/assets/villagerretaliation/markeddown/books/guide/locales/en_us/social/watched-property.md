# Watched Property

Villagers can confront players for opening, breaking, or stealing from watched village containers. Detection depends on the protected structure or property data, nearby witnesses, line of sight, contents, and server settings.

- Opening a watched container can create suspicion even if you take nothing.
- Taking items can cost reputation according to what was removed.
- Breaking a generated container counts its dropped contents, so smashing a full store can be worse than opening an empty one.
- Returning later does not guarantee the same villagers have forgotten what happened.

:::notice{type="warning"}
An ordinary chest near a village is not automatically safe or automatically protected. Datapacks define generated village property, and the server controls witness rules.
:::

If confronted, stop interacting with the property and use peaceful recovery methods from [Reputation](../start/reputation.md).
