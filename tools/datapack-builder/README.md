# Villager Retaliation Datapack Builder

Open `index.html` in a browser to create, import, preview, and export Villager Retaliation datapacks.

The builder is a static site. It emits the current wiki paths for dialogue, notifications, gifts, pacification payments, story discovery, preset names, and `pack.mcmeta`, then exports them as a datapack zip with root-level `pack.mcmeta`.
